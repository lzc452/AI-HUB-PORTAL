# Dashboard 组件规格

## DOM

`dashboard-layout > dashboard-header + body(sidebar + content)`

- Dashboard Header 高度 `60px`。
- Sidebar 宽度 `220px`，浅灰背景，菜单项高度 `42px`。
- Active 菜单黑字、白底与细边框。
- 内容区最大宽度 `1040px`，padding `32px`。

## 评论页

- 顶部标题与说明。
- 双 Tab：收到的回复、我的评论。
- 筛选行：资源类型、排序。
- 评论项显示作者、时间、正文、原评论摘要、资源名称与类型标识。
- 移动端 Sidebar 改为 Header 下方横向菜单，评论元数据换行。
