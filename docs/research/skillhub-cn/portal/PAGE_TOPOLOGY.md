# 页面拓扑

## 全局骨架

1. 固定顶部 Header，高度约 `61px`，白色半透明背景，滚动后保持可见。
2. 主内容采用居中宽幅容器；列表页内容密度高，详情页为主栏与右侧操作栏。
3. 公共 Footer 使用三列信息结构，桌面宽屏展开，移动端纵向堆叠。
4. Dashboard 使用独立 Header 与左侧 Sidebar，内容区维持白底和浅灰分隔。

## 首页

1. Hero：中心标题、副标题、安装说明与主按钮。
2. 核心能力轮播：横向大卡，包含 Hunt、Plugin、企业专区等入口。
3. 榜单：昨日榜首大卡与今日排行列表。
4. Plugin 展示：左文案右产品截图，下方三张精选卡片。
5. 发布可信度：左侧垂直能力导航，右侧大图与指标。
6. 平台指标与企业服务大卡。
7. 部门/企业卡片网格与分页。
8. 技能包横幅与 Footer。

## 资源列表

1. 页面标题、数量和简短说明。
2. 一级 Tab：全部、下载量、最近上新等。
3. 右侧筛选：来源、分类、能力/认证状态、搜索、列表/卡片切换。
4. 高密度资源行：图标、名称、认证、摘要、统计、作者；整行可点击。
5. Empty、Loading、Error 与分页占用同一内容框架。

## 资源详情

1. 顶部面包屑。
2. 资源标题区：图标、名称、作者、标签、摘要、统计与收藏。
3. 主内容 Tab：概述、版本/文件、交付或安装、评论、安全报告。
4. 主栏渲染 Markdown、截图和结构化元数据。
5. 右栏提供主要安装/使用操作、版本与兼容信息。
6. 评论锚点由 `#comment-{commentId}` 定位。

## 应用猎手

1. 周期标题与说明。
2. 当前榜单，前三名强化排名视觉。
3. 普通条目包含图标、应用摘要、票数与投票按钮。
4. 历史周期通过 Tab 或下拉切换。

## 部门中心

1. 标题与部门搜索。
2. 部门卡展示名称、简介、成员与资源数量。
3. 部门详情含简介、负责人、资源分类 Tab 与成员摘要。

## SkillPackage

1. 专家包说明 Hero。
2. 三列卡片网格；卡片包含包名、说明、Skill 数量与更新信息。
3. 详情页展示按任务顺序排列的 Skill 清单。

## Dashboard

1. 左侧导航：个人中心、发布、设置、收藏、评论。
2. 个人中心：四类资源统计、审核状态与最近更新。
3. 发布：先选 App、Skill、Plugin、MCP，再进入对应步骤表单。
4. 收藏：资源类型筛选与卡片列表。
5. 评论：`收到的回复` 与 `我的评论` 双视图，带资源类型、排序和分页。
